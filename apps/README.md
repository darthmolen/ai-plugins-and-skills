# Apps

Small programs that act on what the skills in this repository leave behind. Skills are
instructions an agent follows; an app is something that runs on your machine whether or not an
agent is in the room.

| App | What it does |
|-----|--------------|
| [reminders-set-outlook](reminders-set-outlook/) | Scans your projects for [`reminders-set`](../skills/reminders-set/) files and mirrors each one into a Microsoft To Do task, with an alert when the reminder asks for one. C# / .NET 10. |

Each app keeps its source under `src/` and its design notes under `docs/`.
