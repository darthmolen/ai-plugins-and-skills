# spec-tier (deprecated)

This skill was renamed `plan-tier`. Invoke `ai-plugins-and-skills:plan-tier` and follow it.

The old name is kept so existing references keep working, and it will be removed in a future major
version of this plugin. "Spec" now means only a system spec or a plan's feature-spec (`system-spec`),
and what the tier sizes is the plan.
