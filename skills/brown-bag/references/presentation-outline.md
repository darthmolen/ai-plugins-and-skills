# Presentation outline template

The speaker's plan. Write it first; the slide outline and participant material derive from it.

```markdown
# <Talk title>

| | |
|---|---|
| Audience | <who, and what they already know> |
| Goal | After this talk, attendees can <observable action> |
| Length | <N> min (<M> min talk, <Q> min questions) |
| Sources | <file or link> — <what this talk takes from it> |
| Template | <brand, template, or "none"> |

## Segments

| # | Segment | Minutes |
|---|---|---|
| 1 | <name> | <n> |
| 2 | <name> | <n> |
| | **Total** | **<M>** |

## 1. <Segment name> (<n> min)

- `[S]` <point> — <source file>, <heading>
- `[P]` <the presenter's own point>
- `[S]` *"<verbatim quotation>"* — <source file>, <heading>

**Demo** (if any): <steps, each one a command or a prompt to type>

## 2. <Segment name> (<n> min)

...

## Questions to expect

- <question> — <answer, with its source or marked [P]>

## Gaps

- <step or fact the talk needs that the sources do not give, and which segment needs it>
```

## Worked example (one segment)

Source: `documentation/ai-fundamentals/cost-and-direction.md` in the presenter's repository.

```markdown
## 2. Two ways to get token spend wrong (6 min)

- `[S]` Most people start in one of two places: spending without direction, or not spending at
  all — cost-and-direction.md, "Two common postures toward token spend"
- `[S]` *"both make the same mistake: managing token count instead of managing the goal."* —
  cost-and-direction.md, "Two common postures toward token spend"
- `[P]` Ask the room which of the two they recognise in themselves.

**Demo:** none.
```
